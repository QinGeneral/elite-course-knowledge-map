## 结论

22 个领域名称均有对应资料。原 Markdown 共 775 条，不能视为全部准确、完整：有副标题误读、系列名或期数错配，以及心理学漏项。

## 核对依据与范围

- 指定 Markdown：`原始领域 Markdown/`，22 份。
- 指定原照片：`地图原照片/`，23 张 HEIC；生成完整 JPEG 阅读副本，原图未修改。
- 课程原文：`课程存档/`，共 2,505 份 Markdown，包含重复存档；匹配使用文件内一级标题，而不只依赖文件名。
- 全部原条目执行标题对照、照片 OCR 定位和正文关键词检索；差异项及漏项结合照片局部重点人工审阅。
- 自动识别不是逐字人工验收。长复合概念、公式、地图概括名可能不会在正文逐字出现，不能仅因关键词未命中认定错配。
- 本次验证的是所给照片与本机课程存档的对应关系，未独立验证存档的官方版本，也未评估课程观点科学有效性。
- 原 Markdown 使用 `.jpeg` 的来源名称，实际照片为同编号 `.HEIC`，在网页中已连到真实照片副本。

## 网页地图字体（2026-10-05更新）

- 列表、概念详情、脑图与核对表采用同一份字号与字形字段；支持字形筛选和统一字体切换。
- 大、中、小字号依据同张照片中概念与副标题的相对字高估算，并以清晰概念人工校准；未逐项人工确认全部字号。它们不是重要性评分，也不对应官方指定数值。

- 生成脚本 `typography.py`；每条数据的 `typography` 字段保留字号依据、相对字高与手写体照片编号。
